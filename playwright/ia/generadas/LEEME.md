# Pruebas generadas con IA (experimento E2)

Guarde aquí las pruebas que generó con el [prompt 02](../../../docs/prompts/02-generar-pruebas-e2e.md), **una carpeta por combinación**:

```text
generadas/
├─ chatgpt-ingenuo/registro.spec.js
├─ chatgpt-guiado/registro.spec.js
├─ claude-code-ingenuo/registro.spec.js
└─ claude-code-guiado/registro.spec.js
```

Cada carpeta aparece como una columna en el reporte de `npm run ia:sabotaje`.

Guarde las pruebas **tal como las entregó la IA**, sin corregirlas: se evalúa lo que produjo la herramienta, no lo que usted habría escrito.
